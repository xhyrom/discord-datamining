**Job Description:**
Discord has a highly engaged community of millions of daily active users who use the platform for many different reasons, but there’s one thing that nearly everyone does: play video games. Discord plays a uniquely important role in the future of gaming, and we are focused on making it easier and more fun for people to hang out before, during, and after playing games.We are seeking a QA/DevOps Engineer&amp;nbsp;to join Discord’s Business Systems team. In this role, you will own automated test suite development and maintenance across Oracle ERP Cloud (Fusion) and Salesforce, with a focus on Tosca-based regression and progression testing. You will embed automated testing into CI/CD pipelines and partner closely with ERP Functional, Technical, and DevOps teams to ensure every release is tested consistently and defects are caught early.
What you'll be doing

Run Oracle ERP Cloud and Salesforce QA automation suites for all quarterly patch upgrades end-to-end.
Review new Oracle and SFDC release features and recommend improvements to existing testing processes.
Build and improve regression and progression test automation in the Tosca environment for Oracle Fusion and Salesforce.
Create, maintain, and update Tosca scripts to reflect system and process changes across GL, AP, AR, and FAH modules.
Lead feature enhancement reviews as part of quarterly patch assessment cycles and new enhancement projects.
Integrate automated test suites into CI/CD pipelines; trigger regression suites automatically on every release candidate build.
Maintain test infrastructure and environments in collaboration with DevOps and ERP Technical teams.
Document test coverage, defect trends, and release readiness in Jira and shared reporting dashboards.

Automation Use Cases

FAH Process Automation:&amp;nbsp;Auto-test Financial Accounting Hub on each new sales item addition to eliminate manual unit testing.
AR Regression Suite:&amp;nbsp;Automated flows for invoicing, receipts, and customer setup across every release.
AP Regression Suite:&amp;nbsp;Payment runs, supplier invoices, holds, and approvals tested automatically on each patch cycle.
Salesforce Tosca Automation:&amp;nbsp;Develop, maintain, and expand automated SFDC test suites in Tosca, integrated with release pipelines.

What you should have

3-5+ years of QA automation experience.
Hands-on Tosca experience for regression and progression test suite development and maintenance.
Experience executing and maintaining automated test cycles for quarterly Oracle patch upgrades.
Familiarity with Oracle ERP Cloud and SFDC release feature review and technical impact assessment.
Experience integrating automated test suites into CI/CD pipelines (Jenkins, GitHub Actions, GitLab CI, or equivalent).
Familiarity with pipeline configuration: triggering regression runs on pull requests and release candidate builds.
Working knowledge of version control (Git / GitHub or GitLab): branching, pull requests, and code review workflows.
Basic scripting capability in Python, Shell, or PowerShell for test utility automation and pipeline support.
Understanding of containerized test environments (Docker); experience running tests in ephemeral containers is a plus.
Jira for defect tracking, test coverage reporting, and sprint participation.
Experience writing and maintaining test documentation: test plans, test cases, regression logs, and release readiness summaries.
Ability to work cross-functionally with ERP Functional Analysts, ERP Technical Developers, and DevOps engineers.
Familiarity with SOX compliance, ITGC controls, and ERP change management practices.

Preferred Qualifications

Oracle Fusion certification or formal training in Oracle ERP Cloud modules.
Experience with SaaS QA automation in a high-growth technology company environment.
Exposure to OIC (Oracle Integration Cloud) or MuleSoft integration testing.
Familiarity with Salesforce test automation frameworks beyond Tosca (Selenium, Provar, or equivalent).
Prior experience working with AMS or managed services vendors in an ERP context.
Knowledge of Oracle quarterly release cycles and technical impact assessments.
Exposure to infrastructure-as-code or environment provisioning concepts (Terraform, Ansible).
