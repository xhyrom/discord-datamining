<h2 id="h_01HR55DRFE0XQKWBFK0TD7BZ6W">What is the Embedded App SDK?</h2>
<p>The Embedded App SDK is a tool that developers can use to turn their eligible game into an Activity playable in a Discord voice channel! (Activities in text coming soon!)</p>
<h2 id="h_01HR55DRFEGCXYFE078JQGVB7B">Why should I use it?</h2>
<p>As a developer, you can take your <a href="#h_01HR55DRFEK5FP4CG9S64JDQKW">eligible</a> game or app to the next level with the Embedded App SDK! By integrating your game into the Discord platform, you're opening the door to a community of potential players who are already using Discord every single day. The SDK allows for incredible levels of built-in social interaction within your games! You can also use the SDK to build rich applications and tools that help Discord users collaborate and create together!</p>
<h2 id="h_01HR55DRFEK5FP4CG9S64JDQKW">Is my App eligible?</h2>
<p>In order to be eligible for creating an Activity using the Embedded App SDK, your application will need to be <a href="https://support-dev.discord.com/hc/en-us/articles/6207083765655-What-is-Bot-Verification">unverified</a>. If you have submitted your application for verification or it has already been verified, it will not be eligible.</p>
<h2 id="h_01HR55DRFE03C2FMFANHEV60TA">How do I get started?</h2>
<p>Head over to the Developer Portal! You’ll find an excellent <a href="https://discord.com/developers/docs/activities/overview">Getting Started Guide</a> there for a great starting point.</p>
<p>Or, you can go directly to the <a href="https://github.com/discord/embedded-app-sdk">Embedded App SDK</a> repo and get started right away!</p>
<h2 id="h_01HR55DRFEBJ5S3AM7KGDXQQ9V">How can people launch my Activity?</h2>
<p class="callout">It is very important to only test activities from developers that you trust. For more information on Private Activity Safety, check out <a href="https://support-dev.discord.com/hc/en-us/articles/21692628851351-Private-Activity-Safety">this</a> article.</p>
<p>Once your Activity is built and ready to play, it might be nice to have some people play it!</p>
<p>We are currently only allowing private testing as this is a developer preview but check out the <a href="https://support-dev.discord.com/hc/en-us/articles/21204493235991-How-Can-My-Friends-Play-My-Activity">How can my friends play my Activity?</a> article for up-to-date information on how people can play your Activity!</p>
<h2 id="h_01HR55DRFERC2MHXDDAWXRE6YJ">Where can I find my Activity’s Application ID?</h2>
<p>At some point, you may need to access your Activity’s App ID.</p>
<p>You are able to do that in the <a href="https://discord.com/developers/applications">Discord Developer Portal</a>. You can find and copy the Application ID under the <strong>General Information</strong> section.</p>
<p><img src="https://support-dev.discord.com/hc/article_attachments/21794784663319" alt="2_.png"></p>
<p>If you received an invitation to become an app tester, you will find the application ID in the request email.</p>
