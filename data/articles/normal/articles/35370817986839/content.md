<h1 id="h_01K7Q39NTJXN478QEC9C50K5MF">What is the Game Servers Feature?</h1>
<p>
  Discord's Game Servers feature lets you create dedicated game servers for
  popular titles — either by unlocking one for your whole community using Server
  Boosts, or by subscribing to your own directly in the Shop — creating seamless
  multiplayer gaming experiences for your community.
</p>
<div class="info-box">
  <strong>Note:</strong> While Game Servers can be set up and accessed through a
  Discord server, anyone with the game server’s IP address can join directly
  from the game, even if they’re not in the Discord server.
</div>
<h1 id="h_how_to_create">How to Create a Game Server</h1>
<p>
  There are two ways to create a Game Server: unlock one for your whole
  community using <strong>Server Boosts</strong>, or subscribe to unlock your
  own directly in the Shop. Pick whichever fits how you want to play.
</p>
<h2 id="h_01K7SFDDY9XXDQSARYEERYTBMH">
  How to Use Server Boosts to Enable Game Servers as a Server Owner/Admin
</h2>
<p>
  The server owner or admin can use any available applied Server Boosts to
  unlock Game Servers.
</p>
<div class="warn-box">
  <strong>Important:</strong> Game servers can’t be disabled within 7 days of
  creation.
</div>
<div class="info-box">
  <strong>Note:</strong> We regularly review and adjust the Boost requirements
  for perks, including Game Servers. If you remove a Boosting perk, the amount
  of Boosts required may be different if you want to reactivate it. The amount
  of Boosts required will always be clear before you activate a perk.
</div>
<p>
  1. With the correct server selected, navigate to the
  <strong>Server Boosts </strong>tab in the upper-left corner. Only server
  admins and owners can view this tab.<br /> 
</p>

<h2 id="h_how_to_purchase">How to Purchase a Game Server Directly</h2>
<p>
  Any Discord user can subscribe to unlock their own Game Server with a payment
  method on file, without needing a server's Boosts.
</p>
<p>
  Since you've subscribed to the Game Server, you're fully in control of the
  game server management — including whether and with whom you share it. Keep it
  private for solo play, share it with a few friends, or post the link somewhere
  bigger; it's entirely your call.
</p>
<p>
  This is a good option if you want to game with friends outside of an existing
  Discord server, or if your server hasn't unlocked Game Servers through
  Boosting.
</p>
<div class="info-box">
  <strong>Note:</strong> Each Discord user can subscribe to up to 5 active Game
  Server subscriptions at a time.
</div>
<p>
  1. Open the <strong>Shop</strong>, then select the
  <strong>Game Servers</strong> tab.
</p>
<figure class="wysiwyg-image">
  <img
    style="aspect-ratio: 5760/4580"

    alt="Shop_(4).png"
    width="5760"
    height="4580"
  />
</figure>
<p>2. Under "Start your own game server," choose the game you want to host.</p>

    width="5760"

<p>
  3. In the Game server setup window, enter a name for your server, choose a
  location, and select a plan.

<p>
  If you have an active Nitro subscription, you'll see a discounted Nitro price
  for eligible plans in addition to the standard price.
</p>

<div class="info-box">
  <strong>Note:</strong> Your Game Server may take up to an hour to become
  available, and you'll see a confirmation once it's ready.
</div>
<p>
  5. Once you've completed checkout and your payment is processed, your Game
  Server subscription is ready to go! You can manage your subscription anytime
  from the <strong>Game Servers</strong> tab in the Shop, or from
  <strong>User Settings &gt; Subscriptions &gt; Game Servers</strong>, and your
  Game Server subscription will renew on a monthly basis until you cancel.
</p>
<p>
  6. Once your Game Server is set up, you can share it with anyone — in a
  channel, a DM, or a group DM — using a shareable link. Selecting the link
  shows the server's info so others can join, without needing to be in a shared
  Discord server with you.
</p>
<h1 id="h_how_to_manage_subscription">
  How to Manage Your Game Server Subscription
</h1>
<p>
  Applies only to Game Servers you pay for directly — Boost-unlocked servers are
  still managed through
  <a href="#h_01K7Q3ATDJ3AX6DW3QPYTM9QKN"
    >How to Modify a Game Server as a Server Owner/Admin</a
  >
  above.
</p>
<p>1. Open User Settings and go to the Subscriptions section.</p>
<p>2. Find the Game Server subscription you want to manage.</p>
<figure class="wysiwyg-image">
  <img
    style="aspect-ratio: 5760/4096"
    src="https://support.discord.com/hc/article_attachments/42495686038935"
    alt="Manage_Subscription_for_Game_Server.png"
    width="5760"
    height="4096"

</figure>
<p><strong>Upgrading your plan:</strong></p>
<ul>
  <li data-list-item-id="e20cac04e911cac31e4b3b5249b61beeb">
    If you upgrade to a higher plan, you're charged a prorated amount
    immediately, and your Game Server is upgraded right away.
  </li>
</ul>
<p><strong>Downgrading your plan:</strong></p>
<ul>
  <li data-list-item-id="e9b7db1ab73f61f30983d5f6fd4c1661a">
    If you downgrade, your Game Server stays on its current plan until your next
    renewal. At renewal, you're charged the lower price and your Game Server is
    downgraded at that time.
  </li>
</ul>
<p><strong>Canceling your subscription:</strong></p>
<ul>
  <li data-list-item-id="e5106778cfde4c2a1988e0b2af03634da">
    Canceling doesn't stop your Game Server right away. You'll keep access until
    the end of your current billing period, after which your server is spun down
    and we won't charge you for any subsequent billing periods after you have
    cancelled.
  </li>
</ul>
<div class="warn-box">
  <strong>Important:</strong> Game Server payments are final and
  non-refundable. <br />If you encounter any technical issues with a Game Server
  subscription you've purchased, contact us at
  <a href="https://dis.gd/support" target="_blank" rel="noopener noreferrer"
    >dis.gd/support</a
  >.
</div>
<div class="info-box">
  <strong>Note</strong>: Game Server subscriptions can't be gifted, and payment
  methods that don't support refunds (like some prepaid or gift balances) can't
  be used for these subscriptions.
</div>
<h1 id="h_01K7Q3AJEEYJ4HQE4VV6RE8CBF">
  What to Know Before Joining Game Servers
</h1>
<p>
  Game servers accessed through Discord are hosted by third-party providers and
  aren’t moderated by Discord. Without Discord's standard safety features, you
  should take extra precautions to protect yourself in these external spaces.
</p>
<p>
  <strong>Before You Join:</strong> Avoid joining servers hosted by people you
  don’t know and trust in real life or from well-known groups you trust. Be
  selective—these servers may have different safety features from those you’re
  used to on Discord, so your choice of which servers to join becomes your
  primary safety measure.
</p>
<p>
  <strong>Protect Your Privacy:</strong> Refrain from sharing personal
  information like your real name, location, age, school, or contact details on
  game servers. Be especially cautious of anyone who tries to move conversations
  to other platforms, offers unexpected gifts or special treatment, or asks you
  to keep interactions secret. These are red flags for potentially harmful
  behavior that can escalate quickly in unmoderated spaces.
</p>
<p>
  <strong>Use Available Safety Tools:</strong> Consider enabling any safety
  features the server offers like chat filters, allowlist controls, and
  moderation plugins. When creating your own server, use allowlist controls to
  limit access to known friends, enable moderation tools, and establish clear
  behavioral expectations from the start. Remember that these tools may differ
  from what you're used to with Discord's built-in protections.
</p>
<p>
  <strong>Trust Your Instincts:</strong> If someone makes you uncomfortable,
  leave immediately. Your safety is more important than game progress,
  maintaining friendships, or avoiding awkwardness. It's never your fault if
  someone acts inappropriately toward you. Report concerning behavior
  <em>happening in the game server</em> to the server admin if you trust them,
  or use the game host's reporting system (like
  <a
    href="https://shockbyte.com/contact"
    target="_blank"
    rel="noopener noreferrer"
    ><span class="wysiwyg-underline">Shockbyte's support form</span></a
  >). If you see behavior that violates our
  <a href="https://discord.com/terms" target="_blank" rel="noopener noreferrer"
    ><span class="wysiwyg-underline">Terms of Service</span></a
  >
  or
  <a
    href="https://discord.com/guidelines"
    target="_blank"
    rel="noopener noreferrer"
    ><span class="wysiwyg-underline">Community Guidelines</span></a
  >
  <em>happening on Discord</em>, please
  <a
    href="https://discord.com/safety/360044103651-reporting-abusive-behavior-to-discord"
    target="_blank"
    rel="noopener noreferrer"
    ><span class="wysiwyg-underline">report it directly to us</span></a
  >.
</p>
<p>
  <strong>Stay Alert:</strong> These servers exist outside Discord's safety
  ecosystem, meaning the automatic detection systems and rapid response teams
  you might expect aren't available. Maintain strong boundaries, be skeptical of
  unusual requests, and prioritize your wellbeing over gameplay.
</p>

<h2 id="h_01K7Q3HT95GSE2TNJ0G0GBHSJD">
  How to Connect to Game Servers by Game
</h2>
<p>
  Once you've joined a Game Server, follow the steps for your specific game
  below to connect and start playing.
</p>
<p><strong>Palworld</strong></p>
<ol>
  <li data-list-item-id="e74621468f126a41033351d81a9cc4e93">
    Launch Palworld.
  </li>
  <li data-list-item-id="e6ed6d9ede2eec98d5834a4ec00bc0d10">
    Choose <strong>Join Multiplayer Game</strong>.
  </li>
  <li data-list-item-id="efac0828fb51ff33f41a79c71de82127a">
    Enter the <strong>IP:Port</strong> of the server.
  </li>
  <li data-list-item-id="e3b414b2e2b20bf624ca2d474c823c28b">
    Select <strong>Connect</strong>.
  </li>
</ol>
<p><strong>Rust</strong></p>
<ol>
  <li data-list-item-id="e41e08803c032c2f96722753b58968c57">
    Press <strong>F1</strong> to open the in-game console.
  </li>
  <li data-list-item-id="e77ec82df90b492e4a06fa981b308fa8c">
    Type client.connect &lt;IP:Port&gt; and press Enter.
  </li>
</ol>
<p><strong>Enshrouded</strong></p>
<ol>
  <li data-list-item-id="e3c25f43ed78aca3f89aa340de9970357">
    In Steam: go to <strong>View → Game Servers → Favorites</strong>.
  </li>
  <li data-list-item-id="ef644ee481cb1bd23da3dd492eb0fe140">
    Select the <strong>+ Add a Server</strong> button and enter the
    <strong>IP:Query Port</strong>.
  </li>
  <li data-list-item-id="ec1baef4664aa0c856efd3a332a51b390">
    The server will appear in <strong>Steam → Favorites</strong> and will show
    up in-game.
  </li>
</ol>
<p><strong>7 Days to Die</strong></p>
<ol>
  <li data-list-item-id="e6491cb0992a022ce8123e246ba4768fd">
    Launch the game and select <strong>Join a Game</strong> from the main menu.
  </li>
  <li data-list-item-id="e56377ad989692ca21f3a985199d997da">
    Press <strong>Connect to IP</strong>.
  </li>
  <li data-list-item-id="ed85477eebb88f89480bb54151d46b607">
    Enter the <strong>IP</strong> before the colon, and the
    <strong>port</strong> after.
  </li>
</ol>
<p><strong>Terraria</strong></p>
<ol>
  <li data-list-item-id="e81f2847efb7eb9cdcafb188718ec3fec">
    Launch Terraria, select the <strong>Multiplayer option</strong>, then select
    the <strong>Join via IP</strong> option.
  </li>
  <li data-list-item-id="ebebf33834f68edd2513667520c04d26b">
    From the character selection screen, either select a character you have
    previously made or make a new character.
  </li>
  <li data-list-item-id="ebdb7e48e35b98f172cbc5c4df809465a">
    Enter your Server's IP address (this is the part before the colon) and your
    Server's Port (this is the part after the colon). (Example:

<h2 id="h_faq_creating_managing">Creating and Managing your Game Server</h2>
<p>
  <strong
    >Q: How many Game Servers can be created in one Discord server?</strong
  >
</p>
<p>A: You can have a maximum of 10 Game Servers per Discord server.</p>
<p>
  <strong
    >Q: Do I need extra Boosts to unlock Game Servers for my server?</strong
  >
</p>
<p>
  A: Game Servers are a separate feature from your server's Boost level. Boosts
  used to level up your server do not count toward unlocking Game Servers. To
  enable Game Servers, you'll need to apply Boosts specifically toward creating
  a game server. Once a game server is created, the Game Servers tab will appear
  in your server.
</p>
<p><strong>Q: How many Boosts does it cost to create a Game Server?</strong></p>
<p>
  A: The number of Boosts required depends on the game and plan you choose. The
  least expensive option starts at 3 Boosts, with certain games and higher-tier
  plans requiring more. All Boosts allocated go directly toward that game
  server, there's no extra Boost cost just to unlock the feature.
</p>
<p>
  <strong
    >Q: What happens to my game server if I no longer have the Server Boosts to
    maintain it?</strong
  >
</p>
<p>
  A: If you do not apply the necessary Server Boosts to maintain the server, the
  Game Server will be deleted after 3 days.
</p>
<p><strong>Q: How can I disable my game server?</strong></p>
<p>
  A: As a server admin or owner, head to the Server Boosts tab &gt; View Game
  Servers and then press Disable Perk under the specific game server you want to
  disable.
</p>
<h2 id="h_faq_billing_subscriptions">Billing and Subscriptions</h2>
<p>
  <strong
    >Q: What's the difference between using Server Boosts and paying directly
    for a Game Server?</strong
  >
</p>
<p>
  A: With Server Boosts, a server owner or admin unlocks a Game Server for their
  whole community using Boosts already applied to the server. Signing up through
  the Shop lets any Discord user subscribe to create a Game Server with their
  own payment method and share it with whoever they choose, without needing a
  server's Boosts.
</p>
<p><strong>Q: Do I need Nitro to pay for a Game Server directly?</strong></p>
<p>
  A: No. Anyone can pay the standard price for a Game Server. If you have an
  active Nitro subscription, you'll see a discounted Nitro price on eligible
  plans.
</p>
<p><strong>Q: Can I get a refund for my Game Server subscription?</strong></p>
<p>A: No, Game Server payments are final and non-refundable.</p>
<p>
  If you encounter any technical issues with a Game Server subscription you've
  purchased, contact us at
  <a href="https://dis.gd/support" target="_blank" rel="noopener noreferrer"
    >dis.gd/support</a
  >.
</p>
<p><strong>Q: What happens when I upgrade my Game Server plan?</strong></p>
<p>
  A: You're charged a prorated amount right away, and your Game Server is
  upgraded immediately.
</p>
<p><strong>Q: What happens when I downgrade my Game Server plan?</strong></p>
<p>
  A: Nothing changes right away. At your next renewal, you're charged the lower
  price and your Game Server is downgraded at that time.
</p>
<p><strong>Q: How many Game Servers can I subscribe to directly?</strong></p>
<p>
  A: Each Discord user can have up to 5 active Game Server subscriptions at a
  time.
</p>
<h2 id="h_faq_sharing_gifting">Sharing and Gifting</h2>
<p>
  <strong>Q: Can I gift a Game Server subscription to someone else?</strong>
</p>
<p>A: No, Game Server subscriptions can't be gifted.</p>
<p>
  <strong
    >Q: Can I share a Game Server I subscribed to with people outside of a
    Discord server?</strong
  >
</p>
<p>
  A: Yes. You can share your Game Server using a shareable link in a channel,
  DM, or group DM, and others can view its info and join without needing to
  share a Discord server with you.
</p>

<h4 class="wysiwyg-text-align-center" id="h_01K7Q3ATDXXJ8WMYKQPFQ2NW7S">
  <span style="color: #666666">Server Status of a Game Server</span> 
</h4>
<p>
  A: Depending on the state of the server, you may see a variety of different
  Server Statuses. Here are all of the available Server Statuses: 
</p>
<ul>
  <li data-list-item-id="e0055e367c41ef93d9443421122d12911">
    <strong>Online:</strong> Server is online and available to join.
  </li>
  <li data-list-item-id="e295d1252b9d6dfdf1d12085adce6b8c0">
    <strong>Offline:</strong> Admin manually stopped the server.
  </li>
  <li data-list-item-id="e8d0367f1c796dfb648a28cc6f2fe0a55">
    <strong>Sleeping: </strong>Server is in hibernation (≥7 days of no
    activity).
  </li>
  <li data-list-item-id="ee6ec761037c943767d4162c0359edf0a">
    <strong>Starting: </strong>Server is in the process of coming online or
    restarting. This can take a few minutes.
  </li>
  <li data-list-item-id="e391a7f5efb646b83112f0bf23a3a54f9">
    <strong>Startup Failed: </strong>Configuration is required. An admin of the
    server must visit the Game Panel to change the configuration.
  </li>
  <li data-list-item-id="e4ac2ab887e45f017b84f7a82f0bf5f71">
    <strong>Missing Stock: </strong>Server location is out of capacity. An admin
    of the server must select a new location in the Game Panel to resolve.
  </li>
  <li data-list-item-id="eb0333b30ea42ce74b1c495e95f260e5f">
    <strong>Unavailable:</strong> Other error. An admin of the server can visit
    the Game Panel for more information.
  </li>
  <li data-list-item-id="e1e044e76d3d52749086dca131bf37c2f">
    <strong>Unknown Error: </strong>An admin of the server will need to reach
    out to Shockbyte support to resolve this issue.
  </li>
  <li data-list-item-id="e0bdee1dde8589deea82ced07340c573d">
    <strong>Deleted: </strong>Server is in the process of being deleted. Once
    deleted, it will disappear from view.
  </li>
</ul>
