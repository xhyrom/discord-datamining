<h1 id="h_what_is_a_server_web_page">What is a Server Web Page?</h1>
<p>
  A <strong>Server Web Page</strong> is a public page on the open web that helps
  people discover and learn about your Discoverable Server. Anyone can see it,
  including people without a Discord account, and search engines like Google can
  show it in their results. Beyond the content you add yourself, it may also
  show content from your server's public channels, such as Channel Summaries and
  Channel Messages. New members can join directly from this page.
</p>
<p>
  To manage which content appears on your page, see
  <a
    href="https://support.discord.com/hc/articles/44049845164823"
    target="_blank"
    rel="noopener noreferrer"
    >Server Web Presence</a
  >.
</p>
<h1 id="h_which_servers_can_create">
  Which servers can create a Server Web Page?
</h1>
<p>Server Web Pages are exclusive to Discoverable Servers.</p>
<p>
  See
  <a
    href="https://support.discord.com/hc/en-us/articles/14078261239831-Clarifying-Server-Types"
    target="_blank"
    rel="noopener noreferrer"
    >Clarifying Server Types</a
  >
  to learn how a Community Server can become Discoverable.
</p>
<h1 id="h_how_do_i_set_up">How do I set up a Server Web Page?</h1>
<p>
  Automatic setup: If you don't set up your own Server Web Page for your
  Discoverable Server, Discord publishes a default one for you, built from your
  server's existing details from the Server Profile. You don't need to do
  anything for your Discoverable Server to have a page.
</p>
<p>To customize your Server Web Page:</p>
<p>1. Open <strong>Server Settings</strong> on Discord desktop or browser.</p>
<p>
  2. Under <strong>Community</strong>, select <strong>Web Presence</strong>.
</p>

<h1 id="h_what_content_should_i_add">
  What content should I add to my Server Web Page?
</h1>
<p>
  All web page content needs to abide by Discord’s
  <a
    href="https://support.discord.com/hc/en-us/articles/4409308485271-Discovery-Guidelines"
    target="_blank"
    rel="noopener noreferrer"
    >Discovery Guidelines</a
  >. Discord’s Trust and Safety team may remove web pages that violate these
  guidelines, and consider whether further action is necessary.
</p>
<p>
  Describe your server in ways that help people find it. When adding content to
  your web page, use words that describe your community accurately and
  specifically. This will help new community members easily find your server
  when they’re searching the web for relevant terms. If your server is for
  underwater basket weaving enthusiasts, use these words rather than more
  generic ones. Your next basket weaver may be just one search term away!
</p>
<h1 id="h_what_content_can_appear">
  What content can appear on my Server’s Web Page?
</h1>
<p>
  <strong>Channel Summaries.</strong> A small slice of what's being talked about
  in your server, directly on your Server Web Page. These automated summaries
  only cover conversations from November 16, 2026, onwards. Admins can change
  which channels they draw from, curate the summaries that are shown, or turn
  them off entirely. Usernames will not be shown in summaries.
</p>
<p>
  <strong>Channel Messages.</strong> From mid-December 2026, answers to
  questions your members sent in public channels can be found in a web search,
  in their own words. Server admins decide which channels take part, and server
  members can opt out of having their own messages appear. Usernames will not be
  shown alongside these messages.
</p>
<p>
  Summaries on the web and Messages on the web are controlled independently;
  each has its own settings for which channels are included. See
  <a
    href="https://support.discord.com/hc/articles/44049845164823"
    target="_blank"
    rel="noopener noreferrer"
    >Server Web Presence</a
  >
  to manage them.
</p>
<h1 id="h_can_i_turn_off">Can I turn off my Server Web Page?</h1>
<p>
  A Server Web Page is a required part of being a Discoverable Server. If you
  don't want a public page, you can turn off Discoverability, which reverts your
  server to a Community Server. See
  <a
    href="https://support.discord.com/hc/en-us/articles/14078261239831-Clarifying-Server-Types"
    target="_blank"
    rel="noopener noreferrer"
    >Clarifying Server Types</a
  >
  for how to turn off Discoverability and what changes when you do.
</p>

</p>

<h1 id="h_boost_level">Does my server need a specific Boost Level?</h1>
<p>
  No. Server Web Pages are available to all Discoverable Servers, regardless of
  Boost Level.
</p>
