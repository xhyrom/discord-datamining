<h1 id="h_01JV2QTH9Q2H7SG0CTYRCE33BT">What is a Data Package?</h1>
<p>
  A <strong>Data Package</strong> is a ZIP folder of files that you can request
  through your <strong>User Settings</strong> that contains all of your Discord
  data for your account. This includes messages, current servers you’re in,
  activity, and more. The files within the ZIP folder are JSON files that can be
  opened easily in Notepad on Windows or through Textedit on MacOS. You can also
  drag and drop them into a browser like Chrome or Firefox. 
</p>

<h1 id="h_01JV2QTH9QSGJ1P7CYCAGEKR3V">
  What information is inside a Data Package?
</h1>
<h2 id="h_01JV2QTH9QT737X7G6X9Q6XC2F">Account</h2>
<p>
  The account folder contains information pertaining to your account. The first
  item you’ll see is the avatar that you are currently using, as well as a
  folder containing any recently-used avatars. If applicable, there will also be
  a folder containing information about any applications you own. Finally,
  you’ll see a JSON file containing the following information about your
  account:
</p>
<ul>
  <li data-list-item-id="ebe3efc925214d87a0428a948b9aa918d">
    Basic information, such as your user ID, username name, phone number, and
    email
  </li>
  <li data-list-item-id="ebfe8bdd47452fbbb066dea8ebefa6047">
    Your account settings
  </li>
  <li data-list-item-id="e743fdfa0e5e2352e639ba3c8a3d28f68">
    Any flags on your account (such as whether you have an active Nitro
    subscription)
  </li>
  <li data-list-item-id="eb371a9210701289c6b9c65e24b488f10">Your IP Address</li>
  <li data-list-item-id="e7759970bc1e05000f270d3e13dd41a81">
    Any accounts you have connected to Discord (“Connections”). (Twitch,
    Twitter, Steam, etc.) 
  </li>
  <li data-list-item-id="e4baa2e62cfd8b101e47f162a32e44544">
    A list of any active sessions you have; PC, Mobile, Browser (IP Address
    included)
  </li>
  <li data-list-item-id="eaab8a5fcbc64bbabd0555dd1e373a062">
    Your user relationships (Friends and Block lists), as well as Friend
    suggestions, and Friends lists from external platforms
  </li>
  <li data-list-item-id="e404132f31fee3035fd46d8a580546213">
    Your payment information, including payment sources, payment history, and
    your Orbs balance and Orbs transaction history
  </li>
  <li data-list-item-id="e18c9a7e2090a1a43bb39af5d31847a09">
    Your developer information (For any webhooks, bots, etc.)
  </li>
  <li data-list-item-id="e2cfaa2fe058a66345e9b4d204c3065f0">
    Activity statistics
  </li>
  <li data-list-item-id="e205bc0fcbc2894f0d2bb44ee9f31578e">
    Notes you have written about other users
  </li>
  <li data-list-item-id="eaf91339afcf94eae0c1fb62ccc8a6764">
    Library applications
  </li>
</ul>
<p>You’ll also see some different age signals we use across the platform:</p>
<ul>
  <li
    class="wysiwyg-list-color"
    data-list-item-id="e9a63b3c0cdce60aec7851ac02367a021"
  >
    <code>date_of_birth</code> - This is the date of birth you provide to us
    when you sign up for the platform. If you’re under 18, it will be anonymized
    to the first of the month (MM-01-YYYY). If you’re over 18, this will be
    fully anonymized, and you’ll see (01-01-0001)
  </li>
  <li
    class="wysiwyg-list-color"
    data-list-item-id="e5af8921c6043737a7d27001514e89a97"
  >
    <code>age_assurance</code> - When you use one of the methods to confirm your
    age, we retain the vendor and method used, as well as the timestamp of your
    verification attempt. 
    <ul>
      <li data-list-item-id="e4adcc496052be35b056c8df24a2985cd">
        <code>estimated_age_group</code> is how we store the outcome of the age
        assurance method you chose, which can be more precise in the case of
        teens (e.g., 13, 14, 15) or broader for adults (e.g., 22-25).  
      </li>
      <li data-list-item-id="ee213d2a2985db4bd1f4ffc6969c451ce">
        <code>inferred_age_group</code> is the age group assigned to you by the
        ML model that estimates your age as part of our overall age assurance
        system (e.g., Teen, Adult).
      </li>
    </ul>
  </li>
  <li data-list-item-id="e05ddfd69cca9c9901a90c753b15f12de">
    <code>predicted_age</code> - This is a different type of age prediction
    model that we use to understand how users interact with Discord and to power
    certain features in the app. This age signal does not determine your age
    group (e.g., Adult, Teen).
  </li>
</ul>
<div class="tip-box">
  <strong>Tip:</strong> If you have recently deleted an avatar image, it may
  still show up in your package.
</div>
<h2 id="h_01JV2QTH9QK6M7GAWDHVQXHKM3">Activity</h2>
<p>
  The activity folder contains four folders, each with a JSON file that has
  information about the actions you have taken on Discord. 
</p>
<ul>
  <li data-list-item-id="e87cd905948d13d175bbc98a147e5b115">
    <strong>Analytics</strong>: This is a record of your actions within Discord.
    The information is used to improve your Discord experience, like improving
    search relevance.
    <ul>
      <li data-list-item-id="e4b9bf82d4dea21943eb5fae39373deb0">
        You can disable the use of tracking analytics here:
        <strong>User Settings</strong> &gt;
        <strong>Data &amp; Privacy</strong> &gt;
        <strong>Use data to improve Discord</strong> 
      </li>
    </ul>
  </li>
  <li data-list-item-id="ed241c591b037440a4b20e0a75333645c">
    <strong>Modeling: </strong>This is data we use to better tailor certain
    parts of Discord to you, like the <strong>Games</strong> tab.
    <ul>
      <li data-list-item-id="eebb2ef9aa0d46c7977358b4ef282af52">
        You can disable the use of this here:
        <strong>User Settings</strong> &gt;
        <strong>Data &amp; Privacy</strong> &gt;
        <strong>Use data to personalize my Discord experience</strong>
      </li>
    </ul>
  </li>
  <li data-list-item-id="edbed7fad0f88d0cbecb19d8b476cc5cf">
    <strong>Reporting</strong>: This folder contains a JSON file with data we
    use in order to operate our business. (Information such as messages sent, or
    your Nitro subscription, as an example.)
  </li>
  <li data-list-item-id="e802d3d5e993834c72a37924c197cf350">
    <strong>Trust &amp; Safety (TNS)</strong>: This folder contains data we use
    for safety purposes. This data is retained for up to 2 years.
  </li>
</ul>
<h2 id="h_01JV2QTH9QQG7959RV63B1NQXV">Activities</h2>
<p>
  The activities folder contains two folders, each with a JSON file that has
  information about 1st-party activities you have participated in on Discord.
</p>
<ul>
  <li data-list-item-id="ecd6d8d33b96db02323c1809b32f68047">
    Activities_1 - This folder will contain some of your
    <a
      href="https://support-apps.discord.com/hc/en-us/sections/26498424335895"
      target="_blank"
      rel="noopener noreferrer"
      >Activities</a
    >
    user data and preferences, as well as activity-specific data about Chess in
    the Park, Checkers in the Park, and Poker Night 2.0
  </li>
  <li data-list-item-id="e602782f9c97ee6e83cbe3d9811a78360">
    Activities_2 - This folder will contain more Activities user data and
    preferences, as well as activity-specific data about Sketch Heads, Watch
    Together, Letter League, Land-io, and Know What I Meme
  </li>
</ul>
<h2 id="h_01JV2QTH9QV7AB3AF0E9YF07J6">Messages</h2>
<p>
  The messages folder contains all the messages that you have sent on Discord.
  Please note that your message folder does not include Customer Support or
  Trust &amp; Safety correspondence as these communications take place outside
  of the Discord application.
</p>
<p>
  The messages you have sent are broken down separately into folders based on
  Direct Messages, Group Messages, and channels that you have chatted in. The
  number for each folder is the Channel ID for where the messages were sent.
  There is a JSON file which also contains a full mapping of Channel ID to
  Channel name for all of the folders included.
</p>
<p>
  When you select a folder, you'll notice it contains a couple items. The first
  is a JSON file which will include information about where the messages in that
  folder were sent. If the folder contains messages from a server, this
  information will include the associated Guild ID, Channel ID, and Channel
  Name. If the folder contains messages from a DM or group chat, this
  information will include the associated Channel ID and User IDs.
</p>
<p>
  The second is a JSON file which contains the transcript of your messages. For
  each message, it will contain the following information:
</p>
<ul>
  <li data-list-item-id="ea4e021f147176e69cc871517ca7eccd4">
    ID: The message ID
  </li>
  <li data-list-item-id="e80d51e2d6ca279dced0edc6696e49403">
    Timestamp: The date and exact time your message was sent
  </li>
  <li data-list-item-id="e36b79740590098c9f313bd507f1507dd">
    Contents: Your message.
  </li>
  <li data-list-item-id="e01530ed1b326f8798d296a22bae29cc5">
    Attachments : A CDN link to any images, or files you included in your
    message
  </li>
</ul>
<div class="tip-box">
  <strong>Tip:</strong> If you manually delete a message - it is no longer
  stored in Discord and therefore will not be included in your Data Package.
</div>
<h2 id="h_01JV2QTH9QRS97WY51DRZTA128">Servers</h2>
<div class="warning-box">
  <strong>Important: </strong>If you leave a server before requesting your Data
  Package, that server may not be included. Your Data Package only includes
  servers you are a member of at the time of the request as well as any
  recently-departed servers.
</div>
<p>
  The servers folder contains information for all of the servers that you are a
  member of. This includes servers that you own. The information provided for
  each is a little different. There is a JSON file which also contains a full
  list of the folders included.
</p>
<p>The folder for a server you own will contain the following:</p>
<ul>
  <li data-list-item-id="ed14d31aa8a7a1ea68b12bb79a401f56d">
    A folder containing emoji that you have uploaded.
  </li>
  <li data-list-item-id="e121e940ce10186fc336d3c86226ef6d6">
    A JSON file containing actions from your Audit Log.
  </li>
  <li data-list-item-id="eafa5eaea54d3af4175f235f8917bf159">
    A JSON file containing a list of your channels along with their permissions.
  </li>
  <li data-list-item-id="e3ba3fcc3a48225ea01f31428ae460f6d">
    A JSON file containing the ID information for the emoji you have uploaded.
  </li>
  <li data-list-item-id="e8af68fcc0b9659aef032d2263ce964ae">
    A JSON file containing the settings for your server (guild).
  </li>
  <li data-list-item-id="edb978b3864720a8273f8d0c99fb833c6">
    A JSON file containing information for any webhook you have implemented.
  </li>
</ul>
<p>
  The folder for a server that you are a member of will contain the following:
</p>
<ul>
  <li data-list-item-id="e7cf0312783e3563a9435985f8e6eab61">
    A JSON file containing actions from the last 90 days that pertain to your
    account from the Audit Log.
  </li>
  <li data-list-item-id="e7fc272de18dde97886ca47d63c0213bf">
    A JSON file containing the server ID and name.
  </li>
</ul>
<h2 id="h_01JV2QTH9QJ0M3MHTTXSRH0TRK">Ads</h2>
<p>
  The Ads folder contains information about advertisements (e.g.:
  <a
    href="https://support.discord.com/hc/en-us/articles/22225719947543-Discord-Quests-FAQ"
    target="_blank"
    rel="noopener noreferrer"
    >Quests</a
  >) that you have interacted with on the platform and traits we use to serve
  ads to you. The Ads folder contains the following:
</p>
<ul>
  <li data-list-item-id="eafce367617303e003363746d2d11c2e1">
    A JSON file containing the status of Quests you’ve engaged with on Discord
  </li>
  <li data-list-item-id="e2bde7a84a158e2e0291c23b2b7c57728">
    A JSON file containing information we’ve associated with you to tailor ads
    to you
  </li>
</ul>
<p>
  Note that some information related to ads, such as when you saw a Quest, will
  be captured in the Activity folder.
</p>
<h2 id="h_01K2Z1F0GK1Z3C7YF0MMS8ND4B">Support Tickets</h2>
<p>
  This folder contains a JSON file with information about tickets you’ve made
  through our Help Center in Zendesk that are tied to your Discord email
  address. Each ticket contains the following information:
</p>
<ul>
  <li data-list-item-id="e7e4a3d665e01c6260f3d0bc37832286f">
    The body of all public comments on the ticket, including the comment’s
    author and creation timestamp
  </li>
  <li data-list-item-id="ecc2c3c9d8627041e5e69e0272a20a784">
    The time the ticket was created
  </li>
  <li data-list-item-id="ed4e32289479a1d565f1611377e923876">
    The status of the ticket
  </li>
  <li data-list-item-id="e6942ed869beaa0bb778501a24053e160">
    The subject of the ticket
  </li>
  <li data-list-item-id="ed013a0528245d8b81152ce9f52531784">The ticket ID</li>
</ul>
