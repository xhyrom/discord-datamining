<h1 id="h_01M2JQE6YY29S2STZMCRH6BKAV">How to Add a Friend</h1>
<div class="info-box">
  <strong>Note</strong>: The maximum number of friends you can have on an
  account is 1,000 (accepted friends only). You can have up to 1,500 pending
  incoming friend requests and 1,000 pending outgoing friend requests. If the
  incoming request limit is exceeded, the oldest pending requests will
  automatically be removed until you're back to 1,000.
</div>
<p>
  Adding a friend on Discord is as easy as 1-2-3! Let’s go over the various ways
  to send friend requests and some common errors you might encounter. 
</p>
<p>
  If you're receiving lots of unwanted friend requests, you may want to ignore
  certain users. Need help managing unwanted friend requests? Learn how to
  ignore users by checking out our
  <a
    href="https://support.discord.com/hc/en-us/articles/28084948873623"
    target="_blank"
    rel="noopener noreferrer"
    ><strong
      ><span class="wysiwyg-underline"
        >How to Ignore Users on Discord</span
      ></strong
    ></a
  >
  article.
</p>
<div class="warn-box">
  <strong>Important: </strong>You will be alerted before accepting a friend
  request from an unfamiliar user. Unfamiliar users are those you do not have
  any mutual friends or shared small servers (&lt; 200 members) with. These
  alerts can help you make more informed decisions about new connections. These
  alerts cannot be turned off at this time regardless if you’re an adult or
  teen.
</div>

<h2 id="h_01M2JQE6Z0S56TG9WDDDJDTY84">Username</h2>
<p>
  <span class="wysiwyg-font-size-x-large"
    ><strong>Desktop/Browser</strong></span
  >
</p>
<p>1. Press on the Discord logo in the top-left corner.</p>
<p>
  2. Next, make sure you have the <strong>Friends</strong> tab selected and then
  press the button that says <strong>Add Friend</strong>.
</p>
<p>
  3. Here you can type in or paste the username of the friend you’d like to
  add. 
</p>
<div class="info-box">
  <strong>Note</strong>: The username needs to be exact, or the request will not
  go through.
</div>
<p>
  4. After typing or pasting in the username, press on
  <strong>Send Friend Request</strong> to send the friend request.
</p>
<p>
  5. You can tell if the friend request went through by tapping on the
  <strong>Pending</strong> tab and seeing it there.
</p>

<p>3. Then, tap <strong>Add by Username</strong>. </p>
<p>
  4. In this <strong>Friends list menu</strong>, you can type or paste in the
  <strong>username</strong> of the user that you want to add. 
</p>
<p>
  5. After you’ve typed or pasted in the <strong>username</strong>, tap
  <strong>Send Friend Request</strong>.

<h2 id="h_01M2JQE6Z3HERZGMHDYSQFE7KE">Profile</h2>
<p>
  <span class="wysiwyg-font-size-x-large"
    ><strong>Desktop/Browser</strong></span
  >
</p>
<p>
  1. Navigate to a <strong>group chat</strong> or a <strong>server</strong> of
  the user you’d like to add. 
</p>
<p>2. Select their profile and then press <strong>View Profile</strong>.</p>
<p>
  3. Next, press <strong>Send Friend Request</strong> to send them a request.
</p>

<p>
  <span class="wysiwyg-font-size-x-large"><strong>Mobile</strong></span>

<p>

</p>
<p>
  2a. Next, if you’re in a group chat, you can tap the
  <strong>user’s profile</strong> to add them in the
  <strong>profile view</strong>. 
</p>
<p>
  2b. If you’re in a server, tap one of the <strong>text channels</strong> in
  the server. Now under the <strong>Member’s list </strong>for the server, tap
  the <strong>profile</strong> of the user you’d like to add.
</p>
<p>3. Press <strong>Add Friend</strong> to add them as a friend.</p>

<h2 id="h_01M2JQE6Z60TWDYTH7YAZS3943">Server Member’s List</h2>
<div class="info-box">
  <strong>Note</strong>: There is not an option to add a friend through this
  right-click method in the server member’s list on mobile - you can only add
  them by tapping their profile.
</div>
<p>
  <span class="wysiwyg-font-size-x-large"
    ><strong>Desktop/Browser</strong></span
  >
</p>
<p>
  1. Navigate to the <strong>server</strong> or <strong>group</strong>
  <strong>chat</strong> of the user you’d like to add.
</p>
<p>
  2. Right-click on their <strong>profile</strong> (or a server message they
  have sent) and then select <strong>Add Friend </strong>in the
  <strong>menu</strong>.
</p>
<p>
  3. There will not be a confirmation pop-up, however, you can check under the
  <strong>Friends</strong> tab to see if the friend request is pending.
</p>

<h1 id="h_01M2JQE6Z8KCFG4DNF79GQ20PT">
  How to Cancel a Pending Friend Request
</h1>
<div class="info-box">
  <strong>Note</strong>: If the friend request has already been accepted, you
  won’t be able to remove the pending request any longer.
</div>
<h2 id="h_01M2JQE6Z8C4SK7KQMRXX9RT4K">Desktop/Browser</h2>
<p>
  1. Press the <strong>Discord</strong> <strong>logo</strong> in the top-left
  corner of the desktop.
</p>
<p>
  2. Next, make sure you have the <strong>Friends</strong>
  <strong>tab</strong> selected and then navigate to <strong>Pending</strong> at
  the top.
</p>
<p>
  3. Here you can select the <strong>X</strong> <strong>button</strong> next to
  the <strong>Friend</strong> <strong>Request</strong> you want to cancel.
</p>

<h2 id="h_01M2JQE6ZAZ06AR8HN3RXE8Z6P">Mobile</h2>
<p>
  1. Tap the <strong>You</strong> <strong>button</strong> on the bottom-right
  corner.
</p>
<p>
  2. Next, press <strong>Your Friends</strong> and then
  <strong>Friend Requests</strong>.
</p>
<p>
  3. Here you can see any received or sent friend requests. To remove the
  request for sent, tap the <strong>X</strong> next to the request. 
</p>
<p>
  4. You should receive a <strong>pop-up confirmation</strong> once it’s been
  removed and you’ll no longer see the request under your
  <strong>pending list</strong>.
</p>

<h1 id="h_01M2JQE6ZB58RXV47VVPCRNV2Z">Common Errors When Adding a Friend</h1>
<h2 id="h_01M2JQE6ZB19P47YM6F99G0NTN">Friend Request Failed</h2>
<p>
  If you go to add a friend and you receive the warning “<strong
    >Friend Request Failed</strong
  >” this is because the user is not accepting friend requests. They will need
  to add you as a friend instead. This means they have their
  <strong>Friend Requests setting</strong> disabled. 
</p>

<h2 id="h_01M2JQE6ZC412ZR5WTYJG3889R">
  Double Check that the Username is Correct
</h2>
<p>
  If you receive an error message that states “<strong
    >Hm, didn’t work. Double check that the username is correct.</strong
  >”, it means the username was not typed or pasted correctly. 
</p>
<p>
  The username needs to be exact, or the friend request will not go through, so
  double check each number, letter, underscore, or period you’ve typed and then
  try submitting the request again.
</p>
<p>
  If you’re still running into an issue adding the friend after confirming that
  you’ve typed their username correctly, you’ll need to reach out to them to see
  if they can send you a friend request instead.
</p>
