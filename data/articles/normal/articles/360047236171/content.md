  whether it's a <strong>Friend</strong>, <strong>Community</strong>, or
  <strong>Discoverable Server</strong>. Learn more in

<h1 id="what-is-a-verified-server">What is a Verified Server?</h1>
<p>
  The <strong>Verified Server Program</strong> lets official game servers get
  recognized on Discord. A Verified badge means the server has gone through
  Discord's verification process, confirming its connection to a game through
  Steam.
</p>
<div class="info-box">
  <strong>Note:</strong> Verification previously extended to large companies,
  films, and musicians. That broader program has been discontinued, and
  verification now applies to games only. Learn more in
  <a
    href="https://support.discord.com/hc/en-us/articles/360001107231-Discord-Verified-Server-Program-FAQ"
    target="_blank"
    rel="noopener noreferrer"
    >Discord Verified Server Program FAQ</a
  >.
</div>
<h1 id="whats-a-discord-partner">What's a Discord Partner?</h1>
<p>
  The Partner Program is closed to new applications. Existing Partnered servers
  keep their status and perks.
</p>
<p>
  The Discord Partner Program is designed to reward quality, engaged servers
  with recognition and extra tools to help them invest in their community.
</p>
<p>
  Partnered servers receive a Vanity URL and an invite splash, along with a
  Server Banner, an animated Server Icon, a Discord Partner badge for both the
  server and the server owner, and Discord Nitro for the owner.
</p>
<h1 id="what-are-the-differences">What are the differences? Can I be both?</h1>
<p>
  Verification and the Partner Program recognize different things. Verification
  confirms a server is the official home for a game, through Discord's
  Steam-based verification process. The Partner Program recognizes quality,
  engaged communities more broadly, regardless of subject matter.
</p>
<p>
  Because the Partner Program is closed to new applications, new servers can't
  apply for Partnered status, including Verified servers. Existing servers that
  hold both statuses will still keep them.
</p>
<p>
  If a server holds both and loses one, it keeps the other. For example, a
  server that's both Partnered and Verified, and loses Partnered status, stays
  Verified and retains any perks tied to Verification.
</p>

<h1 id="partnered-verified-and-discoverable-servers">
  Partnered, Verified, and Discoverable Servers
</h1>
<p>
  Partnered and Verified status don't change your server type. However, Verified
  servers automatically qualify as Discoverable Servers.
</p>
