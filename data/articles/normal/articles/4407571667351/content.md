<p>
  When submitting legal process to Discord, law enforcement should include the
  <strong>User ID</strong> or <strong>username</strong> of the Discord account
  in question so we can identify it accurately. Here’s how to find both on the
  Discord desktop and mobile apps.
</p>

<p>
  To ensure Discord’s prompt compliance with the legal process, the user
  information provided needs to uniquely identify a Discord account. We can
  locate users in our system by user identification number, username, and email.
  The user identification number is the most preferred.
</p>
<p>
  Failure to include requisite information will result in Discord’s inability to
  comply with the legal process. IP addresses, usernames (without the
  discriminator), and server nicknames can be helpful to support any of the
  above, however, they are insufficient to uniquely identify an account as they
  can be shared by multiple Discord accounts. Usernames are unique at any given
  time, but they can be changed. Legacy usernames are unique when they include
  the discriminator. If you provide a username, consider identifying the
  relevant date(s) that the username was in use.
</p>
<h1 id="h_find_user_id">How to Find a User ID</h1>
<p>
  Each Discord user is assigned a unique numeric user identification number
  (UID), typically 17–19 digits. UIDs are unique to each user and cannot be
  changed.
</p>
<h2 id="h_user_id_desktop">Desktop App</h2>
<p>
  1. You must enable Developer Mode first. You'll find Developer Mode by
  pressing on the cogwheel in the bottom left corner to get to User Settings,
  then scroll down the sidebar and select Developer. Toggle on Developer Mode.
</p>

<h2 id="h_user_id_mobile">Mobile App</h2>
<p>

  bottom left corner, then tap on <strong>Settings</strong>. Scroll down to
  <strong>App Settings</strong> and select <strong>Advanced</strong>. Toggle on
  <strong>Developer Mode</strong>.

<h1 id="h_find_usernames">How to Find Usernames and Discriminators</h1>
<p>
  Each Discord user has a unique username which are lowercase, alphanumeric, and
  limited to certain special characters. You can learn more about our usernames
  <a
    href="https://support.discord.com/hc/en-us/articles/12620128861463-New-Usernames-Display-Names"
    >here</a
  >. Usernames can be changed by users and display names for users may differ
  from their usernames. Discord also changes usernames once an account is
  deleted. Provide the username if the UID is unavailable.
</p>
<h2 id="h_username_desktop">Desktop App</h2>
<p>
  1. Navigate to the server or direct message with the user in question. You can
  press on the user’s avatar (profile icon) to reveal their Profile or
  right-click the direct message with the user and select Profile.
</p>
<p>The profile will show the user’s username underneath their display name.</p>
<p>
  2. Highlight the username, then right-click and select <strong>Copy</strong>,
  or press Ctrl+C (Cmd+C on Mac), to copy it to your device’s clipboard.
</p>

<h2 id="h_username_mobile">Mobile App</h2>
<p>
  1. Navigate to the server or direct message with the user in question. You can
  long-press the direct message with the user and select
  <strong>Profile</strong>. Tap on the three dots icon in the upper right corner
  of the profile.
</p>
<p>
  2. Press <strong>Copy User Info</strong>, then select Copy Username to put on
  your device’s clipboard.
</p>
