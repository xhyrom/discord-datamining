<p>
  <strong>Web Presence</strong> is where you control what content from your
  Discoverable Server can appear publicly on its Server Web Page and in search
  engines like Google.
</p>
<div class="info-box">
  <strong>Note:</strong> Web Presence settings are available on desktop and
  browser only at this time. Only the server owner or members with the
  Administrator permission can change them, and bots can't change them.
</div>

<h1 id="h_how_to_open_web_presence">How to Open Web Presence</h1>
<p>1. Open <strong>Server Settings</strong>.</p>
<p>

<h1 id="h_01M5ZK33FZERN93SZH6Z5AMRCR">What You Can Control Here</h1>
<p>
  <strong
    >Controls for both Channel Summaries on the web and Channel Messages on the
    web roll out gradually starting October 27, 2026.</strong
  >
</p>
<p>
  Server Web Presence manages two independent features. Each has its own toggle
  and its own list of eligible channels. Both toggles are under
  <strong>Discoverable Content on Web Pages</strong> and are on by default.
</p>
<ul>
  <li data-list-item-id="e4898ae5daa184a4925d045927a123926">
    <strong>Channel Summaries on the web:</strong> These show a small slice of
    what's being talked about in your server, directly on your Server Web Page.
    These automated summaries focus on active conversations from November 16,
    2026, onwards. Admins can change which channels they draw from, curate the
    summaries that are shown, or turn them off entirely. Usernames and avatars
    will not be shown in summaries.
  </li>
</ul>

<h4 class="wysiwyg-text-align-center" id="h_caption_channel_messages_settings">
  <span style="color: #666666">Channel Messages Settings</span>
</h4>
<h2 id="h_what_makes_a_channel_eligible">What makes a channel eligible?</h2>
<p>
  From November 16, 2026, summaries from public channels in your Discoverable
  Server may appear on your Server Web Page. Starting mid-December 2026,
  messages from public channels can appear too. Private channels, like
  role-restricted channels, are never included.
</p>
<p>
  Channels taking part in Channel Summaries or Channel Messages are labeled,
  with an icon in the channel header.
</p>
<p>
  Public channels in Discoverable Servers are included by default. You can
  change which ones are included at any time. Read below for more information on
  toggles for Channel Summaries on the web and Channel Messages on the web.
</p>
<h2 id="h_channel_summaries_on_the_web">Channel Summaries on the Web</h2>
<p>
  Choose which channels contribute to Channel Summaries on your Server Web Page.
  You can:
</p>
<ul>
  <li data-list-item-id="e59a871e2924294ea95a0e7010628d400">
    Select or deselect individual channels
  </li>
  <li data-list-item-id="e984231bdfd8c7dda08916c6b80d86dee">
    Turn Summaries off entirely for your server
  </li>
</ul>
<p>
  Use <strong>Search channels</strong> to find a specific channel, or select
  <strong>Select All</strong> or <strong>Deselect All</strong> to change every
  channel at once. Select <strong>Save Changes</strong> when you're done.
</p>
<p>
  Summaries are generated automatically and are subject to Discord's
  <a
    href="https://support.discord.com/hc/en-us/articles/4409308485271-Discovery-Guidelines"
    target="_blank"
    rel="noopener noreferrer"
    >Discovery Guidelines</a
  >. Discord's Trust &amp; Safety team can remove summaries that violate these
  guidelines.
</p>
<h2 id="h_channel_messages_on_the_web">Channel Messages on the Web</h2>
<p>
  Choose which channels are eligible to have members' messages shown on the
  server web pages. You can:
</p>
<ul>
  <li data-list-item-id="e541d8b66ac3282fba3913a1a56e6d3ee">
    Select or deselect individual channels, independently of your Channel
    Summaries selections
  </li>
  <li data-list-item-id="e81228bac342cb68bb35a5e133532f29f">
    Turn Channel Messages off entirely for your server
  </li>
</ul>
<h2 id="h_setting_this_when_creating_a_channel">
  Setting This When Creating a Channel
</h2>
<p>
  When you create a public text channel in a Discoverable Server, the channel
  creation window includes a <strong>Discoverable</strong> section where you can
  choose <strong>All Content</strong>, <strong>Summaries Only</strong>,
  <strong>Messages Only</strong>, or <strong>Off</strong>. This only changes the
  channel you're creating. For private channels, this section shows as
  <strong>Disabled</strong>.
</p>
<h1 id="h_removing_content_from_the_web">Removing Content from the Web</h1>
<p>To remove a Channel Summary or Channel Message from your Server Web Page:</p>
<ul>
  <li data-list-item-id="e4c16cfc9421c391a7f10ff491f926c07">
    <strong>Delete the message.</strong> Deleting a message removes it from the
    Discord app and Discord web pages.
  </li>
  <li data-list-item-id="e25fad42650e0755bbe7448c5409c1326">
    <strong>Turn off the feature.</strong> Toggling off Channel Summaries or
    Channel Messages stops new content from being generated or shown going
    forward, but content already published may remain visible until individually
    removed.
  </li>
  <li data-list-item-id="eec4b6221baebd5a81e761b2cfa4b1768">
    <strong>Remove specific channels.</strong> Deselect individual channels
    under <strong>Web Presence</strong> settings to stop them from contributing
    new content.
  </li>
</ul>
<p>
  Keep in mind that while Discord removes content from its own pages, search
  engines have their own caching and indexing processes. It may take additional
  time or action for content to stop appearing in search results.
</p>
<h1 id="h_frequently_asked_questions">Frequently Asked Questions</h1>
<p><strong>Q: How do I know if my server is Discoverable?</strong></p>
<p>
  A: Open <strong>Server Settings &gt; Access &gt; Discoverable</strong>. If
  your server meets all requirements and <strong>Server Discovery</strong> is
  turned on, your server is Discoverable, and the settings in this article apply
  to it. If you can't open the <strong>Discoverable</strong> tab, or your server
  doesn't meet all Server Discovery requirements, it isn't Discoverable yet. See
  <strong>What if my server doesn't meet requirements?</strong> above, or learn
  how a server becomes Discoverable in
  <a
    href="https://support.discord.com/hc/en-us/articles/14078261239831-Clarifying-Server-Types"
    >Clarifying Server Types</a
  >. 
</p>
<p><strong>Q: What happens if I don't do anything?</strong></p>
<p>
  A: If you don't do anything, starting November 16, 2026, Channel Summaries may
  start appearing on your Server Web Page, and Channel Messages will roll out
  starting mid-December 2026. If you haven't published your own Server Web Page,
  a default page goes live for you on November 16, 2026.
</p>
<p>
  In some regions, members' Channel Messages setting is off by default, so their
  messages won't appear unless they turn it on.
</p>
<p>
  If you want to turn off or change these settings, visit
  <strong>Server Settings &gt; Community &gt; Web Presence</strong>.
</p>
<p>
  <strong
    >Q: If I turn off Channel Summaries or Channel Messages, does existing
    content come down immediately?</strong
  >
</p>
<p>
  A: Turning off a feature stops new content from being generated or shown going
  forward. Content already published may remain visible until it's individually
  removed. Deleting a message removes its visibility on the Discord app and
  Discord web pages. While Discord has its own
  <a
    href="https://support.discord.com/hc/en-us/articles/5431812448791-How-long-Discord-keeps-your-information"
    >data retention policy</a
  >, we do not control how long others may retain cached or indexed copies of
  content. Search engines have their own deletion processes and retention
  policies so it may take additional action or time for content to stop
  appearing in their results.
</p>
<p>
  <strong>Q: Can I stop my server from appearing on the web entirely?</strong>
</p>
<p>
  A: Turning off both Channel Summaries and Channel Messages stops new content
  from appearing, though content already published may remain visible (see the
  FAQ above). Your Server Web Page stays live while your server is Discoverable.
  To remove your Server Web Page, turn off Discoverability, which changes your
  server back to a Community Server. See
  <a
    href="https://support.discord.com/hc/en-us/articles/14078261239831-Clarifying-Server-Types"
    >Clarifying Server Types</a
  >
  for how to do this.
</p>
<p>
  <strong
    >Q: Do Channel Summaries and Channel Messages use the same channel
    selections?</strong
  >
</p>
<p>
  A: No. They're independent. You can select different channels for each, or
  turn one off without affecting the other.
</p>
<p><strong>Q: How are Channel Summaries created?</strong></p>
<p>
  A: Discord creates Channel Summaries using AI, based on recent discussions in
  your server's public channels. Summaries may not always be accurate.
</p>
<p><strong>Q: Is Discord selling user messages to AI companies?</strong></p>
<p>
  A: No. Nothing has changed. We are making Discord content easier to find if
  admins and users choose to make their content available on the web.
</p>
<p><strong>Q: What happens if my server stops being Discoverable?</strong></p>
<p>
  A: If your server is no longer Discoverable, your Server Web Page is taken
  down, and Channel Messages and Channel Summaries turn off so your server no
  longer contributes new content to these features. However, this does not
  automatically remove content that was already published on the web.
</p>
<p>
  To remove a specific message from Discord web pages, delete the original
  message in Discord. Search engines may still have cached copies, even after
  the message is deleted. Discord doesn't control those copies, so removal from
  search results may require additional time or action through the search
  engine.
</p>
<p>
  See
  <a
    href="https://support.discord.com/hc/en-us/articles/14078261239831-Clarifying-Server-Types"
    target="_blank"
    rel="noopener noreferrer"
    >Clarifying Server Types</a
  >
  for more about what changes when you turn off Discoverability.
</p>
<p>
  <strong
    >Q: Does turning off a feature here affect my members' individual privacy
    settings?</strong
  >
</p>
<p>
  A: No. Members have their own separate control over whether their individual
  messages can appear. Members control this with the
  <strong
    >Show my message content from Discoverable channels on web pages</strong
  >
  setting in <strong>User Settings &gt; Data &amp; Privacy</strong>.
</p>
<p>
  Region, age, and each member's own privacy setting can affect whether a
  specific message is eligible. See
  <a
    href="https://support.discord.com/hc/articles/44302319454359"
    target="_blank"
    rel="noopener noreferrer"
    >Discoverable Content on Web</a
  >
  to learn more about individual user controls.
</p>
