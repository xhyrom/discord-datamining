<h1 id="h_01M1FHY61TR4ZDEHB42GJ7658R">Custom Typing Indicator: What Is It?</h1>
<p>
  “Is typing…” is the default message you see when someone's composing a
  message. With <strong>Custom Typing Indicator</strong>, you can replace that
  default message with your own 3 emojis and status word whenever you're the
  <strong>only</strong> person typing. 
</p>
<div class="info-box">
  <span style="color: #434343"
    ><strong>Note:</strong> If more than one person is typing at the same time,
    everyone's indicator returns to the default “is typing…” message.</span
  >
</div>
<p>
  Currently available on <strong>mobile</strong> only, this appears anywhere you
  can chat on Discord, including <strong>direct messages</strong>,
  <strong>text channels</strong>, <strong>forum channels</strong>, and
  <strong>voice channel chats</strong>.
</p>
<p><strong>There are three parts you can customize:</strong></p>
<ul>
  <li data-list-item-id="ec0ad4f39ec341dd8f7b3171b079df48d">
    <strong>Emoji: </strong>Select 3 unique emoji that you already have access
    to.
  </li>
  <li data-list-item-id="ed4551206d951b3d72cca0103d6d38626">
    <strong>Animation: </strong>Choose an animation style:
    <strong>Pulse</strong>, <strong>Ring</strong>, or <strong>Wave</strong>, or
    select <strong>None</strong> to turn animation off.
  </li>
  <li data-list-item-id="e877f324a92d50a8330973a132d195999">
    <strong>Status: </strong>Pick a status word from a preset list to replace
    "typing," like "is yapping…" or "is daydreaming…"
  </li>
</ul>

<h1 id="h_01M1FHY620SWH1T4SKCGZB0T9Y">

<div class="info-box">

<p>
  3. Select an <strong>emoji</strong> slot to open the emoji picker. Selecting

<p>

  our options of preset status words to replace “typing”.
</p>
<p>
  6. Once you've made a change, select <strong>Apply</strong> to save your
  customized typing indicator.

<h1 id="h_01M1FHY62D6Z24DBDQNWHTZDB9">Nitro vs. Non-Nitro Access</h1>
<ul>
  <li data-list-item-id="e82a04eafa4753872541bf61c01c9146d">
    <strong>Nitro members: </strong>Can fully customize and save their typing
    indicator, including emoji, animation, and status word. This feature is
    <strong>not</strong> available for Nitro Basic.
  </li>
  <li data-list-item-id="edfdadeb02ddbba909be7cbbb73d51f41">
    <strong>Non-Nitro members: </strong>Can preview the customization options
    but need a Nitro subscription to save and use them.
  </li>
</ul>
<h1 id="h_01M1FHY62EPVACXYBXWSSNEJT2">Frequently Asked Questions</h1>
<p><strong>Q: What does Custom Typing Indicator do?</strong></p>
<p>
  A: It lets you replace the default “is typing…” message with up to 3 custom
  emoji, a motion style, and an alternative verb, whenever you're the only
  person typing in a conversation.
</p>
<p><strong>Q: Can I turn off the custom typing indicator?</strong></p>
<p>
  A: There isn't a way to disable the custom typing indicator. If you'd like to
  reduce the intensity of its animation, you can turn on
  <strong>Reduced</strong> <strong>Motion</strong> in
  <strong>User Settings &gt; Accessibility</strong>, which minimizes motion
  effects across Discord.
</p>
<p>
  <strong
    >Q: What happens if more than one person is typing at the same time?</strong
  >
</p>
<p>
  A: Everyone's typing indicator returns to the default “is typing…” message
  until only one person is typing again.
</p>
<p><strong>Q: Do I need Nitro to use this feature?</strong></p>
<p>
  A: You need a
  <a
    href="https://support.discord.com/hc/en-us/articles/115000435108-What-are-Nitro-Nitro-Basic#h_01JXDBAR0WH1RJAGD4N99QN13J"
    target="_blank"
    rel="noopener noreferrer"
    ><span class="wysiwyg-underline">Nitro</span></a
  >
  subscription to save and use a custom typing indicator. This feature is not
  available for Nitro Basic. Non-Nitro members can preview the customization
  options, but can't save or apply them.
</p>
<p><strong>Q: Where can I set up my custom typing indicator?</strong></p>
<p>
  A: As part of this experiment, you'll be able to set it up from either
  Settings or your Profile, but you'll only see one of the two. This experiment
  is currently mobile only.
</p>
<p>
  <strong>Q: Will everyone see my custom typing indicator the same way?</strong>
</p>
<p>
  A: Not always. If a server has the
  <strong>Use External Emoji</strong> permission turned off, other members in
  that server will see the default "…" in place of your custom emoji, but
  they'll still see your custom status word.
</p>
<p><strong>Q: Where does my custom typing indicator show up?</strong></p>
<p>
  A: It shows up for others anytime you are typing on Discord, including direct
  messages, text channels, forum channels, and voice channel chats. It only
  appears if you are the only person typing. 
</p>
<p><strong>Q: Is this feature available to everyone?</strong></p>
<p>
  A: Not yet. This is currently an experiment and only available to a limited
  number of Nitro subscribers on mobile. 
</p>
<p><strong>Q: Can I choose any word for my status?</strong></p>
<p>
  A: You'll choose from a preset list of status words rather than writing your
  own. The current options are: is yapping…, is venting…, is oversharing…, is
  barking…, is babbling…, is daydreaming…, and is meowing….
</p>
<p><strong>Q: Is there a quick way to try different combinations?</strong></p>
<p>
  A: Yes. Select <strong>Surprise Me</strong> to get a random combination of
  emoji, animation, and status word.
</p>
<p>
  <strong>Q: Can I set a different typing indicator for each server?</strong>
</p>
<p>
  A: No. Your custom typing indicator applies everywhere you chat on Discord and
  can't be set on a per-server basis.
</p>
<p>
  <strong
    >Q: What happens if I tap on someone else's custom typing indicator?</strong
  >
</p>
<p>
  A: If you're able to edit your own typing indicator, tapping on someone else's
  opens the same bottom sheet used to customize yours, so you can quickly set
  one up for yourself. If you can't edit your typing indicator, tapping won't
  open this shortcut.
</p>
